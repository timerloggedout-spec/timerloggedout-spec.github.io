## Operating principles

- Evidence over unsupported claims.
- Dashboards are projections; repositories and their histories are authoritative.
- Stale, partial, or missing data remains visibly uncertain.
- Proposed, implemented, executed, validated, and promoted are separate states.

### Evidence and freshness

Read a status together with its source record, generation time, source window, and version. Delivery evidence includes the proposal, branch, pull request, checks, merge commit, publication workflow, and deployed artifact. A passing test validates its tested scope; a merge proves the change entered the target branch; a deployment receipt proves the publication workflow ran; a live scan verifies the current public response.

Generated feeds should expose freshness explicitly. A stale feed carries a stale state, and a missing feed remains an observable gap. Follow the source links on each project page to inspect the implementation, tests, and history behind the visible experience.

### Human-directed agent model

AI collaborators support research, planning, implementation, review, and operational analysis under human direction. Each task carries a scope, an authorized action set, and a verification path. Display monikers support attribution while provider, model, adapter, execution role, and repository remain separate facts. Prefer bounded work, isolated branches, explicit acceptance checks, and receipts that identify changed files and commits.

### Open retrieval formats

The site publishes [llms.txt](/llms.txt), [llms-full.txt](/llms-full.txt), a [Markdown sitemap](/sitemap.md), and a [project glossary](/glossary.md). HTML and Markdown are parallel text representations. GitHub Pages serves static Markdown routes and alternate links; per-response Link headers and Accept-based content negotiation require a programmable edge or application server.

### Agent Readability badge

The public badge appears only after a fresh verified scan records a score of at least 95/100, a scan URL, and a verification timestamp. Unknown or lower scores keep the badge hidden.
