StudySprint · v1.0.0

A study plan you can trust.

Drop a syllabus → see today's plan in under 10 seconds. StudySprint is a Strands-wired agent built for first-generation college students: a verified syllabus becomes a week-by-week study plan, recall quizzes, and re-plans on missed weeks — with no-guilt mechanics. Missed = re-planned, never a broken streak.

Open the web app Watch the demo Releases View the code

The trust receipt comes first

Before StudySprint plans anything, it shows you what it actually fetched — course, weeks, due dates, and a hash of the evidence — and only plans after you confirm. If a syllabus claim can't be verified, the agent abstains instead of planning from it. That is a feature, surfaced honestly, not an error state.

Built for the daily loop

The features StudySprint shipped for the submission window — plus the plan underneath them.

🧾

Trust receipt before planning

The UI shows what was fetched — course, weeks, due dates, hash — and only plans after the student confirms. The evidence gate, made visible.

📅

Today view

One card: today's sessions, one tap to start, one tap “I missed this” → instant re-plan, no guilt UI. Today first — the plan is a means; today is the product.

⏱️

Time-budget reflow

“I have 25 min today, not 45” → the plan re-flows around the student's real day: job shifts, commute, life.

✅

Daily check-in, recovered weeks

A 30-second check-in — done / partial / missed per session — feeds the re-plan. Streaks are shown as recovered weeks, never as broken chains.

💬

Plain-language mode

No jargon anywhere. Every agent action explains itself in one sentence a first-gen freshman can act on.

🗂️

Week-by-week plan + quizzes

Each topic gets a learn block and a retrieve block, recall quizzes per week, and missed weeks are carried forward and flagged — 12 sessions in the sample plan above.

📖

Multi-pass RSVP reader

Reading material, section by section: pass 1 skim, pass 2 focused re-read, one-tap term flagging for the words that need a second look. Shipped in v0.3.0 (study_reader.py).

🔎

Reading pipeline

A finder sweeps the reading and builds a term bank — the vocabulary the plans and quizzes draw from (study_pipeline.py).

🗓️

Multi-course + .ics

More than one course at a time — and the plan exports as an .ics calendar file that drops into the calendar the student already uses (study_courses.py).

🧠

Memory methods

Method of loci and pomodoro sessions built into the plan, with reminders that nudge the next step (study_memory.py).

Hashed receipts — every decision shows its evidence set Accessible status — icons + words, color never the only signal Privacy, plainly — “Your syllabus stays on your device. No account is required to build a study plan.”

How it works

STEP 1

Bring a syllabus

A syllabus file becomes a verified evidence set — the same stamped-evidence shape as the evidence gate it extends.

STEP 2

Confirm the receipt

You see exactly what was fetched before anything is planned. Unverified claims stop the plan — the agent abstains.

STEP 3

Study today, re-plan freely

Today's card, check-ins, and quizzes run the daily loop. Miss a week and the sessions carry forward — re-planned, never punished.

No leaderboards — no comparing students No paywall on re-planning or quizzes No planning from an unverified syllabus One thumb, one hand, on a bus — primary actions in reach

Try it in 60 seconds

Three doors, one working app, sample course already loaded. Pick by where you're standing:

Door 1 — web (~10 seconds). Open the web app in any modern browser. Press Start Today's Sprint, flip the card, grade it. Works offline after the first load.

Door 2 — terminal (~1 minute). git clone https://github.com/timerloggedout-spec/studysprint && cd studysprint && pip install textual fsrs genanki && python3 tui.py — eight tabs, from Today to Export.

Door 3 — Android (~1 minute). Download the latest studysprint.apk and open it on the phone; the release carries SHA256SUMS and a trust block if you want to verify before installing.

Get StudySprint

StudySprint is open source — and the web app is live: open it in your browser, or run it locally from the repo. Read the receipts, and check the tests yourself.
