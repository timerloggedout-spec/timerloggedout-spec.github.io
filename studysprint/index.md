# StudySprint — a study plan you can trust

StudySprint is a study-planning agent for first-generation students. A verified syllabus becomes a week-by-week study plan.

## Product principles

- A trust receipt is shown before planning.
- A Today view makes the next study actions clear.
- Time-budget reflow adapts the plan when available time changes.
- No-guilt replanning supports realistic recovery rather than punishing missed work.

## Foundation

StudySprint is built on the Delphi Oracle evidence-gate foundation. The public project page links to the source repository and release information. Consult those source records for current implementation and release status.
